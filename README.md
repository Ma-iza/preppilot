# PrepPilot 📱

PrepPilot is a Flutter-based mobile application designed to help students track internship and placement applications, assessments, interviews, and upcoming deadlines.

## 🛠️ Tech Stack

* **Flutter**
* **Dart**
* **REST API**
* **JSON**
* **Git & GitHub**

## 📁 Project Structure

```text
lib/
├── main.dart
├── models/
│   └── application.dart
├── screens/
│   ├── login_page.dart
│   ├── dashboard_page.dart
│   ├── applications_page.dart
│   └── application_detail_page.dart
├── services/
│   └── application_service.dart
└── widgets/
    └── application_card.dart
```

## 🚀 Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or VS Code

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/preppilot.git
```

Navigate to the project:

```bash
cd preppilot
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
